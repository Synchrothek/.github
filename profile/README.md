**Sendungen aus der ARD Mediathek und der ZDFmediathek gemeinsam und synchron schauen, egal wo ihr seid.**

Synchrothek ist eine kostenlose Browser-Erweiterung für Chrome und Firefox. Jede Person schaut im offiziellen Player der Mediathek. Synchronisiert werden nur Play, Pause und Position, Videos werden nicht kopiert. Ohne Konto nutzbar, ohne Werbung und Tracking.

**English:** Synchrothek is a free browser extension for Chrome and Firefox for watching programmes from the German public broadcasters' media libraries (ARD Mediathek, ZDFmediathek) together, in sync. Everyone watches in the official player; only play, pause and position are synchronised. Usable without an account, no ads, no tracking. The server is open source and self-hostable. More at [synchrothek.de/en](https://synchrothek.de/en/).
